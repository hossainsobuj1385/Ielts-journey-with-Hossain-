## 📌 1. Project Overview / প্রজেক্ট ওভারভিউ

### English
**IELTS Journey with Hossain** is an all-in-one educational platform engineered specifically for IELTS candidates. It integrates a **Telegram Bot (Telegraf)**, a mobile-first **Telegram Mini App (React + Tailwind CSS)**, an **Express.js REST API**, a **MySQL / MariaDB database** with connection pooling and normalized schema, and a full-featured **Admin Panel** for instructor Hossain.

Key Features:
- 🚀 **Telegram Mini App**: Frictionless launch inside Telegram with automatic HMAC-SHA256 user authentication.
- 🌱 **Practice Roadmap (অনুশীলন রোডম্যাপ)**: Step-by-step foundation to advanced English (Level 0 to Band 8) with interactive quizzes and immediate grammar feedback.
- 🤝 **Peer Follow & Chat Request System (ফলো ও চ্যাট রিকুয়েষ্ট)**: Follow high-scoring mentors and peers, send chat requests, accept incoming practice invitations, and chat directly in real time.
- 📚 **Curriculum & Lesson Engine**: Structured lessons for Grammar, Vocabulary, Writing, Reading, Speaking, and Listening with video masterclasses and progress tracking.
- 📄 **Google Drive PDF Library**: Free access to Cambridge test materials, predicted speaking cue cards, and essay templates hosted securely on Google Drive.
- 💬 **Interactive Community & Comment Threads**: Threaded replies, likes, instructor endorsements, and moderation reports.
- 🎫 **Lightweight Support Desk**: Students submit questions with subject/message threads and receive direct answers from instructor Hossain.
- 🔐 **Free Student Email Verification (ইমেইল কোড যাচাইকরণ)**: Instant 6-digit verification code system granting verified student status and green badges.
- 📱 **WhatsApp & Facebook Integration**: Students add WhatsApp ID and Facebook profile links to connect easily for speaking practice.
- 🚫 **Block & Unblock Protection**: Block abusive or unwanted users with one click, declining pending requests and managing blocked users in a dedicated tab.
- 📺 **YouTube Video Integration**: Flexible video attachment for any lesson and roadmap section with responsive playback.
- 🛡️ **Instructor Admin Control Center**: Manage lessons, practice roadmaps, Google Drive PDFs, categories, comment moderation, student statuses, and broadcast notifications.
- 💾 **1-Click Full Data & Code Backup Export**: Download complete system state in JSON format at any time directly from the app or admin panel.
- ☁️ **Botkeep.cloud & Production Ready**: Seamless deployment on Botkeep Node.js hosting, cPanel, or VPS.

## 🤖 4. Telegram Bot Creation / টেলিগ্রাম বট তৈরি

1. Open Telegram and search for `@BotFather`.
2. Send `/newbot`.
3. Choose a display name: `IELTS Journey with Hossain`.
4. Choose a unique username ending in `bot` (e.g. `ielts_hossain_bot`).
5. Copy the generated **HTTP API BOT_TOKEN** (e.g. `7891234567:AAHk...`).
6. Set Bot Commands in BotFather:
   Send `/setcommands`, select your bot, and paste:
   ```text
   start - Welcome message and open app
   app - Launch Telegram Mini App
   home - Curriculum overview
   lessons - Browse featured lessons
   pdfs - Google Drive study materials
   profile - View your progress & bookmarks
   support - Contact instructor Hossain
   help - How to use this platform
   ```

## 🗄️ 5. Database Setup (MySQL / MariaDB) / ডাটাবেজ তৈরি

### Step 1: Create Database
Log in to your MySQL terminal or phpMyAdmin:
```sql
CREATE DATABASE ielts_journey CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### Step 2: Import Schema & Seed Data
Run the SQL scripts located in the `database/` directory:
```bash
mysql -u your_user -p ielts_journey < database/schema.sql
mysql -u your_user -p ielts_journey < database/seed.sql
```
*(In phpMyAdmin: Select `ielts_journey` database -> Click "Import" tab -> Upload `database/schema.sql` -> then upload `database/seed.sql`)*

## 🔐 6. Environment Configuration (.env) / কনফিগারেশন

Create a `.env` file in the project root by copying `.env.example`:
```bash
cp .env.example .env
```

Edit `.env` with your actual credentials:
```env
# Telegram Bot Configuration
BOT_TOKEN=7891234567:AAHk_your_real_bot_token_here
TELEGRAM_WEBAPP_URL=https://your-domain.botkeep.cloud

# MySQL / MariaDB Database Configuration
DB_HOST=localhost
DB_PORT=3306
DB_NAME=ielts_journey
DB_USER=root
DB_PASSWORD=your_actual_mysql_password
DB_CA=

# Admin Authorization (Comma-separated Telegram User IDs)
ADMIN_TELEGRAM_IDS=123456789,987654321

# Server Settings
NODE_ENV=production
PORT=3000
```

> **How to find your Telegram User ID:**  
> Message `@userinfobot` on Telegram to get your numeric ID (e.g. `123456789`), then add it to `ADMIN_TELEGRAM_IDS`.

## ☁️ 9. Botkeep.cloud Deployment / Botkeep ডিপ্লয়মেন্ট

Botkeep.cloud supports Node.js applications with automated port binding and continuous running.

1. **Upload Code**: Upload project files to Botkeep (excluding `node_modules` and `.git`).
2. **Environment Variables**: In the Botkeep dashboard, add all variables from `.env.example`:
   - `BOT_TOKEN`
   - `TELEGRAM_WEBAPP_URL`
   - `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`
   - `ADMIN_TELEGRAM_IDS`
   - `NODE_ENV=production`
3. **Build Command**: `npm run build`
4. **Start Command**: `npm start`
5. The application listens on `0.0.0.0` and uses the port assigned by Botkeep automatically (`process.env.PORT`).

## 📂 10. Google Drive PDF Setup Guide / গুগল ড্রাইভ পিডিএফ সেটআপ

To add study materials to the PDF library:
1. Upload your PDF file to your **Google Drive**.
2. Right-click the PDF -> Select **Share** -> Under General Access, change to:  
   **"Anyone with the link" (Viewer)**.
3. Click **Copy link**.
4. Log into the **Admin Panel** -> Navigate to **PDF Library** -> Click **Add PDF**.
5. Paste the copied Google Drive link (e.g. `https://drive.google.com/file/d/1BxiMVs.../view?usp=sharing`).
6. Give it a title and description, then click **Save PDF**.

## 🛡️ 11. Security Best Practices / সিকিউরিটি নিয়মাবলী

- **No Secrets in Frontend**: `BOT_TOKEN`, `DB_PASSWORD`, and admin credentials are never sent to the browser.
- **HMAC-SHA256 Server Verification**: Telegram `initData` is validated on the backend using the bot token hash.
- **Parameterized SQL**: All database queries use prepared statements to eliminate SQL Injection risks.
- **RBAC Admin Enforcement**: Admin privileges are verified on every single `/api/admin/*` request against `ADMIN_TELEGRAM_IDS`.

## 🛠️ 12. Troubleshooting / সমস্যা ও সমাধান

| Problem | Likely Cause | Solution |
|---|---|---|
| Bot doesn't reply to `/start` | `BOT_TOKEN` missing or incorrect in `.env` | Verify token from `@BotFather` in `.env` |
| PDF shows "Access Denied" | Google Drive link is set to Restricted | Change file sharing in Drive to "Anyone with the link can view" |
| Admin panel button not visible | Telegram ID is not in `ADMIN_TELEGRAM_IDS` | Get numeric ID from `@userinfobot` and add to `.env` |
| MySQL Connection Refused | Incorrect `DB_HOST` or firewall | Check MySQL host, user, password, and port (3306) |
